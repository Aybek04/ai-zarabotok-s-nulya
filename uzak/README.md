# Узак — агент по проектам (Claude Haiku): один мозг, два устройства

Ты общаешься с Узаком на компе и на ноутбуке, а помнит и думает он в одном месте — на компе.

```
 НОУТБУК                                   КОМП
 ┌───────────────┐   HTTP + токен    ┌──────────────────────────────┐
 │ chat.py       │ ────────────────► │ brain.py (мозг Узака)        │
 │ scanner.py ───┼── индекс проектов►│  • Claude Haiku 4.5          │
 └───────────────┘                   │  • индекс обеих машин        │
                                     │  • общая история беседы      │
 КОМП: chat.py ─────────────────────►│  • память (заметки о тебе)   │
                                     │  • сам пересканирует комп    │
                                     └──────────────────────────────┘
```

- **brain.py** — мозг. Запускается только на компе. Хранит всё в `data/`, ходит в Claude API (ключ нужен только тут).
- **chat.py** — чат. Одна и та же копия на обеих машинах. При старте сканирует проекты своей машины и отправляет мозгу.
- **scanner.py** — находит проекты (папки с `.git`, `package.json`, `pyproject.toml`, `Cargo.toml`, `CLAUDE.md`, `SKILL.md` и т.д.) и собирает: стек, README, ветку, последний коммит, незакоммиченные файлы, remote.

Что Узак умеет: перечислить проекты на обеих машинах, рассказать про любой, сравнить (где свежее, где висят незакоммиченные правки), искать по README/коммитам, читать файлы и git-лог проектов **на компе**, запоминать важное о тебе (`remember`). Беседа общая: начал с ноутбука — продолжил на компе.

## Установка (обе машины)

Нужен Python 3.10+.

```bash
git clone https://github.com/aybek04/ai-zarabotok-s-nulya.git
cd ai-zarabotok-s-nulya/uzak
pip install -r requirements.txt
cp config.example.json config.json      # Windows: copy config.example.json config.json
```

Придумай токен (одинаковый на обеих машинах):
```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

## Комп (мозг)

`config.json`:
```json
{
  "machine": "pc",
  "brain_url": "http://127.0.0.1:8765",
  "token": "<твой токен>",
  "scan_roots": ["C:/Users/<ты>/Projects", "D:/dev"],
  "brain": { "host": "0.0.0.0", "port": 8765, "model": "claude-haiku-4-5" }
}
```

Ключ Claude API (https://console.anthropic.com → API Keys) и запуск:
```bash
# Windows (PowerShell)
setx ANTHROPIC_API_KEY "sk-ant-..."     # один раз, потом открыть новое окно
python brain.py

# macOS / Linux
export ANTHROPIC_API_KEY=sk-ant-...
python brain.py
```

В другом окне на компе: `python chat.py`.

Автозапуск мозга на Windows: Планировщик заданий → «При входе в систему» → `pythonw.exe C:\...\uzak\brain.py` (рабочая папка — `uzak`).

## Ноутбук

Ноутбуку нужно достучаться до компа. Проще всего — **Tailscale** (бесплатно, работает и из дома, и вне дома): поставь на обе машины, войди одним аккаунтом, возьми IP компа вида `100.x.y.z`. В одной Wi‑Fi сети можно и локальный IP компа (`ipconfig` → IPv4) — тогда разреши порт 8765 в брандмауэре Windows.

`config.json` на ноутбуке (раздел `brain` не нужен, API-ключ не нужен):
```json
{
  "machine": "laptop",
  "brain_url": "http://100.x.y.z:8765",
  "token": "<тот же токен>",
  "scan_roots": ["C:/Users/<ты>/Projects"]
}
```

```bash
python chat.py
```

## Пользоваться

```
python chat.py                       # обновить индекс этой машины и болтать
python chat.py --no-scan             # без пересканирования
python chat.py "что у меня висит незакоммиченным?"   # один вопрос
python scanner.py --print            # посмотреть, что находит сканер
```

В чате: `/scan` — обновить индекс, `/status` — когда какая машина синхронизировалась, `/reset` — забыть беседу (память-заметки остаются), `/exit`.

Примеры вопросов:
- «Какие проекты есть на ноуте, которых нет на компе?»
- «Над чем я работал на этой неделе?»
- «Расскажи про проект бота, что там в README и на чём он написан»
- «Запомни: до конца месяца хочу запустить продажи гайда на Gumroad»

## Заметки

- Индекс ноутбука обновляется, когда ты запускаешь там `chat.py` (или `scanner.py` — можно повесить на Планировщик). Комп Узак пересканирует сам каждые 30 минут (`rescan_minutes`).
- Файлы проектов ноутбука Узак напрямую не читает — только сводку из индекса (README, стек, коммиты).
- Данные мозга: `data/index_*.json`, `data/history.json`, `data/notes.json`. Не коммитятся (`.gitignore`).
- Порт открыт только для тех, кто знает токен; не выставляй его в интернет напрямую — используй Tailscale/локальную сеть.
- Модель меняется в `brain.model` (например, на `claude-sonnet-5-5`, если захочется умнее).
